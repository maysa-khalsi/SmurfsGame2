# 🎮 Guide de redémarrage - Smurfs Maze Adventure

## ⚠️ ACTION REQUISE

L'application est actuellement en cours de débogage. Vous devez la **redémarrer** pour que les modifications prennent effet.

### 🔴 Arrêtez l'application
```
Raccourci clavier: Shift + F5
```
Ou cliquez sur le bouton **STOP** dans Visual Studio (carré rouge dans la barre d'outils).

### 🟢 Relancez l'application
```
Raccourci clavier: F5
Ou: Ctrl + Shift + F5 (redémarrage complet)
```

## 🚀 Démarrage rapide (après redémarrage)

1. Le jeu lance le "Smurfs Maze Adventure"
2. Vous voyez un **vrai labyrinthe** (murs marron foncé, chemins verts clair)
3. Le **Schtroumpf** blanc est en haut à gauche
4. La zone **END** jaune est en bas à droite
5. **Naviguez** en utilisant les flèches directionnelles
6. **Collectez** les objets rouges/bleus pour regagner de la santé
7. **Évitez** les araignées et mouches
8. **Atteignez** la zone END pour gagner !
